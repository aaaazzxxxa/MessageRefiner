# 개떡찰떡

> 대필 없이, 쓴 문장만 찰떡같이.

개떡찰떡은 SillyTavern 입력 메시지를 보내기 전에 다듬는 메시지 후처리 확장입니다. 입력에 없는 내용을 새로 쓰는 대필 확장이 아니라, 사용자가 이미 작성한 한국어와 영어 문장의 문법과 문체를 정돈하는 데 초점을 맞춥니다.

![개떡찰떡 UI 목업](assets/preview.png)

현재 버전: `0.1.0-beta.8`

요구 버전: SillyTavern `1.18.0` 이상

## 기능

- **살짝 교정**: 맞춤법, 띄어쓰기, 조사, 어순, 호응, 반복을 중심으로 최소한만 수정합니다.
- **찰떡 교정**: 번역투, 문장 호흡, 리듬, 어색한 표현까지 웹소설 문체에 가깝게 다듬습니다.
- **한국어·영어 지원**: 원문의 언어를 자동으로 감지해 번역하지 않고 같은 언어로 교정합니다. 한영 혼합문도 각 부분의 언어를 유지합니다.
- **빠른 적용**: 입력창 위 떡 아이콘에서 살짝 교정 또는 찰떡 교정을 골라 입력창에 바로 적용합니다.
- **편집 탭**: 원문과 결과를 각각 보존하고 직접 수정한 뒤 입력창에 적용할 수 있습니다.
- **안돼 지시사항**: 추가하면 안 되는 내용과 규칙을 직접 편집할 수 있습니다.
- **금지단어**: 태그 형식으로 단어를 쌓고 결과에서 다른 표현으로 대체하도록 지시합니다.
- **되돌리기**: 마지막 적용 전 입력으로 한 번 되돌릴 수 있습니다.
- **프롬프트 공개**: 실제 전송되는 기본/찰떡/안돼 지시사항을 모두 화면에서 확인하고 수정할 수 있습니다.
- **연결 프로필 선택**: 현재 연결을 사용하거나 후처리 전용 연결 프로필을 따로 선택할 수 있습니다.
- **이동 가능한 탭**: 작업 탭을 입력창에서 떼어 원하는 위치로 옮기고 다시 도킹할 수 있습니다.
- **표시 ON/OFF**: 작업 탭의 `X`, 마술봉 확장 메뉴, 설치된 확장 설정에서 표시 상태를 바꿀 수 있습니다.
- **세션 디버그 로그**: 요청 프롬프트, 결과, 오류를 확인하고 복사할 수 있습니다.

## 설치

1. SillyTavern에서 **확장 프로그램** 패널을 엽니다.
2. **확장 설치**를 선택합니다.
3. 이 저장소의 GitHub URL을 붙여 넣습니다.
4. 설치 후 SillyTavern을 새로고침합니다.

수동 설치 시 저장소 폴더를 다음 위치에 넣습니다.

```text
SillyTavern/data/<사용자>/extensions/SillyTavern-MessageRefiner
```

또는 전체 사용자용 확장 폴더에 설치할 수 있습니다.

```text
SillyTavern/public/scripts/extensions/third-party/SillyTavern-MessageRefiner
```

## 사용법

### 바로 다듬기

1. 평소처럼 입력창에 메시지를 작성합니다.
2. 입력창 위 오른쪽의 떡 아이콘을 누릅니다.
3. **살짝 교정** 또는 **찰떡 교정**을 고릅니다.
4. 결과가 현재 입력창에 바로 적용됩니다.
5. 필요하면 표시되는 **되돌리기**를 누릅니다.

결과는 자동으로 전송되지 않습니다.

### 직접 편집하기

1. 입력창 위 **메시지 다듬기**를 누릅니다.
2. 원문을 수정하고 **살짝 교정하기** 또는 **찰떡 교정하기**를 누릅니다.
3. 결과를 직접 확인하거나 수정합니다.
4. **입력창에 적용**을 누릅니다.

모드를 고르면 원문칸에 교정 범위가 안내됩니다. 원문과 결과를 새로 시작하려면 **비우기**를 누릅니다.

### 지시사항

- **기본 지시사항**은 두 모드에 항상 적용됩니다.
- **찰떡 지시사항**은 `찰떡 교정` 모드에만 추가됩니다.
- **안돼 지시사항**과 **금지단어**는 두 모드에 항상 적용됩니다.
- 지시사항은 한국어와 영어 어느 쪽으로 작성해도 함께 해석되며, 지시사항의 언어 때문에 결과 언어가 바뀌지 않습니다.

최종 조합은 다음과 같습니다.

```text
살짝 교정 = 기본 지시사항 + 안돼 지시사항 + 금지단어 + 원문
찰떡 교정 = 기본 지시사항 + 찰떡 지시사항 + 안돼 지시사항 + 금지단어 + 원문
```

지시사항과 금지단어는 작업 탭의 톱니 버튼에서 편집합니다. 확장 프로그램 설정창에는 연결 프로필, 탭 표시 설정, 디버그 로그만 표시됩니다.

### 탭 이동과 닫기

- **메시지 다듬기** 바 왼쪽의 손잡이를 끌면 입력창에서 분리되어 화면 위의 원하는 위치로 이동합니다.
- 분리된 상태에서 바의 핀 버튼을 누르면 입력창 위로 돌아옵니다.
- 바의 `X`를 누르면 작업 탭 전체가 숨겨집니다.
- 마술봉 확장 메뉴의 **개떡찰떡 탭: 켜짐/꺼짐**을 누르면 바로 표시 상태가 바뀝니다.
- 설치된 확장 설정의 **입력창 위 개떡찰떡 탭 ON/OFF**에서도 다시 켤 수 있습니다.

## 연결과 데이터

- 별도 API 키를 요구하지 않습니다. 현재 SillyTavern 연결을 사용하거나 기존 연결 프로필을 별도로 선택할 수 있습니다.
- `generateRaw()`를 사용하므로 캐릭터 카드와 채팅 기록을 프롬프트에 포함하지 않습니다.
- 현재 입력 원문과 화면에 공개된 지시사항만 현재 연결된 모델 제공자에게 전송합니다.
- 자동 전송 기능은 없습니다.
- 디버그 로그는 현재 브라우저 세션의 메모리에만 보관되지만 원문, 프롬프트, 결과가 포함될 수 있습니다.

## 베타 주의사항

- 모델에 따라 원문 보존 강도가 다를 수 있습니다. 중요한 메시지는 편집 탭에서 결과를 확인하세요.
- 일부 커스텀 테마는 입력창 주변 배치를 변경하므로 위치가 다르게 보일 수 있습니다.
- 현재 되돌리기는 마지막 적용 1회만 지원합니다.
